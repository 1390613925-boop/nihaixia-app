# 覓源方｜品牌规范

## 标准名称

- 中文主名称：**覓源方**
- 普通话读音：**mì yuán fāng**
- 简体检索别名：**觅源方**
- 拉丁字母写法：**MIYUANFANG**
- 英文辅助写法：**Miyuan Formula**（仅作国际化辅助，不替代中文主名称）

产品界面、桌面名称、启动页、关于页、分享内容和安装包统一使用繁体“覓源方”。“觅源方”仅用于搜索关键词、用户输入兼容及未来的商店检索描述。

## 名称含义

- **覓**：主动寻访、辨察，不把结果预设为唯一答案。
- **源**：回到经典条文、资料出处与辨证依据。
- **方**：既指经方、方剂，也指方法、路径与方向。

名称整体表达“循源索方、据证而查”的产品定位，适合资料检索、经典阅读与辨证辅助工具，不把软件结果表述为医生结论。

## 品牌定位

> 面向中医学习者与临证工作者的离线经典资料与辨证辅助工作台。

### 推荐品牌短句

- 主短句：**循经典之源，索辨证之方**
- 功能短句：**辨证有序，典籍可查**
- 应用描述：**经方、本草、腧穴与经典资料的离线检索工作台**

## 文字使用规则

1. 首次出现写作“覓源方”，不拆字、不加空格。
2. 不使用“覓源方大师”“神医”“自动开方”等夸大或误导性表述。
3. 医学资料的作者、出处和学术名称保持原样，不因品牌更名而替换。
4. 技术兼容标识（Flutter package name、Android applicationId、签名别名、更新仓库地址）保持不变。
5. 历史版本日志可以保留当时的旧名称；当前界面和新发布内容只使用“覓源方”。

## 视觉语言

- 主色：墨青（Ink Teal）
- 辅助色：黛蓝（Deep Indigo-Blue）
- 功能强调：铜金（Bronze Gold）
- 浅色背景：青灰／宣纸白
- 深色背景：深墨蓝灰
- 图标：现代细线图标
- 造型：中等圆角仅用于入口；检索结果使用紧凑分隔列表

避免大面积朱红、明黄，以及印章、卷轴、竹简等具象仿古元素。

## 文件与发布命名

- 免卡密版：`覓源方_v版本号_无加密版_日期.apk`
- 卡密版：`覓源方_v版本号_卡密版_日期.apk`
- Release 标题：`覓源方 v版本号`
- 分享页脚：`来自「覓源方」App`

## 名称风险提示

正式商业发布前，应分别进行软件、医疗服务、教育培训等相关类别的商标近似检索，并核对应用商店、域名及社交账号可用性。普通网页没有明显同名结果并不等于商标一定可注册。
